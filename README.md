# SportsView

**SportsView** is a polished video hub for the official **NBA, NFL, and MLB** YouTube channels.

## 🌐 Use SportsView on the web

**[Open the live SportsView website](https://fred-systems.github.io/SportsView/)**

The website is the actual SportsView interface — not a README or documentation page. It includes the channel tabs, official video library, search, player controls, responsive layout, and selectable YouTube playback methods.

## 📱 Android app

The Android version provides the same SportsView experience with additional device features such as fullscreen/landscape playback, persistent player preferences, updates, and the optional calculator launcher disguise.

## ✨ Highlights

- NBA, NFL, and MLB tabs
- Official-channel video library
- Search within the selected official channel
- Previous / next video controls
- 10-second rewind and forward
- Seekable progress bar
- Fullscreen and landscape viewing
- Compact, Standard, and Cinema viewing modes
- Multiple YouTube player methods
- Player-method preference saved on the device
- Responsive desktop and mobile web interface
- SportsView favicon and app branding
- Android calculator launcher mode with a normal calculator interface

## 🔒 No general YouTube browsing

SportsView is designed as a focused sports-video viewer rather than a general YouTube browser. The video library is restricted to the selected official sports channel.
